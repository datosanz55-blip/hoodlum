# STUDIO OS — портфолио в виде рабочего стола

Одностраничный сайт-портфолио: человек сидит за столом посреди поля, поверх —
рабочий стол с папками, окнами, доком и меню-баром. Всё на чистом HTML/CSS/JS,
без сборки, без фреймворков, без зависимостей.

## Запуск

```bash
python3 -m http.server 8000
# открыть http://localhost:8000
```

Деплой — любой статический хостинг: GitHub Pages, Netlify, Vercel, Cloudflare Pages,
обычный `nginx`. Собирать нечего, просто выложить папку.

## Что нужно заполнить

Весь текст, контакты, кейсы и цены лежат в **`assets/js/data.js`**.
Больше никуда лезть не нужно — всё, что помечено `TODO`, это заглушка.

| Секция в `data.js` | Что задаёт |
|---|---|
| `profile` | имя бренда, специальность, город, часовой пояс для часов в меню-баре |
| `contacts` | Telegram, Instagram, WhatsApp, почта. Пустая строка `''` — пункт исчезает из дока и контактов |
| `about` | текст о себе, цифры, стек, принципы работы |
| `works` | кейсы: задача, решение, результат в цифрах |
| `services` | тарифы и что в них входит |
| `process` | этапы работы |
| `faq` | частые вопросы |
| `readme`, `trash` | тексты двух шуточных окон |
| `DESKTOP_ITEMS` | какие папки лежат на столе и порядок |
| `DOCK_ITEMS` | что в доке внизу |

## Свой фон вместо нарисованного

Сцена нарисована в SVG, но её можно перекрыть своей картинкой:

```
assets/img/wallpaper.png
```

Как только файл появится, сайт покажет его вместо SVG — трогать код не нужно.
Если файла нет или он не загрузился, остаётся SVG-сцена.

- Формат: PNG или JPG, положить строго по пути выше (имя тоже `wallpaper.png`).
- Размер: горизонтальная, примерно 2560×1440. Она кадрируется `object-fit: cover`
  по центру, поэтому **важное держи в середине кадра** — на телефоне края обрежутся.
- Левая треть остаётся свободной: там лежат иконки папок.
- Тёмная тема просто затемняет фон сверху — отдельная ночная картинка не нужна,
  но если захочется, можно добавить второй `<img>` и переключать по `data-theme`.

## Как устроен код

```
index.html            разметка + SVG-сцена
assets/css/style.css  токены, темы, окна, адаптив
assets/js/data.js     ← весь контент
assets/js/scene.js    процедурная трава, облака, звёзды, параллакс
assets/js/audio.js    фоновый эмбиент на Web Audio (без аудиофайлов)
assets/js/wm.js       оконный менеджер: drag, resize, фокус, сворачивание
assets/js/apps.js     содержимое окон и SVG-иконки
assets/js/app.js      загрузка, иконки стола, док, меню-бар, контекстное меню
```

## Что умеет

- Окна: перетаскивание, ресайз, сворачивание, разворот, фокус, `Esc` — закрыть.
- Иконки стола двигаются мышью, позиция запоминается в `localStorage`.
- Рамка выделения по фону, контекстное меню на правую кнопку.
- Три темы: день → закат → ночь. Первая загрузка выбирает тему по местному времени.
- Фоновая музыка: генерируется в браузере, ноль загруженных мегабайт.
- Горячие клавиши: `T` — тема, `M` — музыка, `W` — работы, `B` — заявка.
- Мобильная версия: окна превращаются в шторки на весь экран, папки — по тапу.
- Заявка собирается в текст и открывается в Telegram — отправляет пользователь сам.
  Бэкенда нет, данные никуда не уходят.
- Уважает `prefers-reduced-motion`: анимации и загрузочный экран отключаются.

## Чего здесь нет

Ни аналитики, ни кук, ни внешних скриптов. Единственный внешний запрос —
шрифты с Google Fonts. Если нужен сайт без внешних запросов совсем, скачай
Unbounded / Inter / JetBrains Mono в `assets/fonts/` и замени `<link>` на `@font-face`.
