# Парсер Яндекс Карт → лиды на digital-услуги

Собирает организации с Яндекс Карт по нишам и городам и проверяет их сайты.
Для каждой компании подбирает, что ей предложить:

| Услуга | Когда предлагается |
|---|---|
| **Создание сайта** | сайта нет, вместо сайта соцсеть или таплинк, сайт не открывается, не адаптирован под телефон, без HTTPS, заброшен (старый ©), сделан на uCoz или Nethouse |
| **SEO/GEO** | рейтинг ниже 4.5, мало отзывов, одна рубрика в карточке, нет title/description, нет микроразметки (её читают поиск и нейросети) |
| **Контент-завод** | нет соцсетей или она одна, на сайте нет блога или статей |
| **Онлайн-администратор** | много отзывов при среднем рейтинге (негатив никто не отрабатывает), нет мессенджеров и чата, связаться можно только по телефону |
| **Автоматизация** | нет онлайн-записи в нишах, где записываются (салоны, клиники, автосервисы, фитнес…), нет Яндекс Метрики, нет чат-бота |

На выходе получается Excel-таблица. Лиды отсортированы по «баллу» и разбиты на приоритеты A, B и C.
У каждого лида есть причины и **черновик первого сообщения** с конкретными замечаниями по этой компании.

## Установка

Нужен Python 3.10+.

```bash
python -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt
playwright install chromium
```

## Запуск

```bash
# Одна ниша, один город
python -m yandex_leads collect -q "барбершоп" --city Казань -o leads.xlsx

# Много ниш и городов из файлов, своя подпись в сообщениях
python -m yandex_leads collect --queries-file examples/queries.txt \
    --cities-file examples/cities.txt --limit 150 \
    --me "Имя, веб-студия X, t.me/username" -o leads.xlsx

# Предлагать только сайты и SEO/GEO
python -m yandex_leads collect -q "стоматология" --city Самара --services site,seo

# Пересчитать таблицу по уже собранным данным (без повторного парсинга)
python -m yandex_leads analyze data/raw.jsonl -o leads.xlsx --min-score 8
```

Откроется окно браузера с Яндекс Картами. Скрипт сам вводит запрос, листает список и забирает данные.
**Если Яндекс покажет капчу, решите её в окне.** Скрипт подождёт до 5 минут и продолжит.
Профиль браузера сохраняется в `.browser-profile/`, поэтому повторная капча бывает редко.

### Основные параметры

| Параметр | Что делает |
|---|---|
| `-q`, `--queries-file` | что искать (можно несколько) |
| `--city`, `--cities-file` | где искать (можно несколько) |
| `--limit` | максимум организаций на один запрос (по умолчанию 100) |
| `--details` | открывать карточки, где в выдаче нет телефона или сайта: дольше, но полнее |
| `--delay` | пауза между действиями в секундах (по умолчанию 2). Увеличьте, если часто появляется капча |
| `--services` | ограничить услуги: `site`, `content`, `seo`, `admin`, `auto` |
| `--min-score` | отсечь «холодные» лиды |
| `--no-audit` | не проверять сайты (быстрее, но выводы беднее) |
| `--me` | подпись в конце черновика сообщения |
| `-o` | `.xlsx`, `.csv` (открывается в Excel) или `.json` |
| `--source api` | брать данные из официального API вместо браузера (см. ниже) |
| `--only-new` | пропускать компании, которые уже есть в `data/raw.jsonl`, и листать выдачу дальше до новых |
| `--proxy` | один прокси для запросов к Яндексу (или `YL_PROXY` в `.env`), например если запускаете с сервера за пределами РФ |

Сырые данные дописываются в `data/raw.jsonl`. По ним можно в любой момент пересчитать лиды
командой `analyze`, например с другими услугами или порогом.

## Ежедневный запуск

Запускайте одну и ту же команду каждый день с `--only-new`.
Компании, собранные в прошлые дни, пропускаются, и в таблицу попадают только новые:

```bash
python -m yandex_leads collect --only-new --queries-file examples/queries.txt --city Челябинск \
    --limit 20 --details --delay 3 --min-score 8 \
    --me "Имя, t.me/ник" -o leads_$(date +%F).xlsx
```

`--limit` задаёт число **новых** компаний на запрос. 13 запросов × 20 дают до 260 компаний,
после отсева `--min-score 8` обычно остаётся порядка сотни лидов. Точная доля зависит от ниши.
Когда в городе новые компании по нише закончатся, парсер скажет «найдено 0».
Тогда добавьте ниши в `examples/queries.txt` или города в `--city`.

История хранится в `data/raw.jsonl`. Не удаляйте этот файл, иначе компании пойдут по второму кругу.

## Что в таблице

Лист **«Лиды»**: приоритет, балл, название, рубрики, адрес, телефоны, сайт, соцсети,
рейтинг, количество отзывов, «что предложить», «почему», черновик сообщения и ссылка на карточку.
Лист **«Сводка»**: сколько лидов на каждую услугу и в каких рубриках.

- **A** (балл ≥ 14) — проблем много, начинайте с них.
- **B** (8–13) — есть пара явных поводов.
- **C** — повод слабый, пишите в последнюю очередь.

## Прокси

```bash
python -m yandex_leads collect -q "барбершоп" --city Казань --proxy "http://user:pass@host:port"
```

Поддерживаются `http://`, `https://` и `socks5://`. Ограничения:
- Chromium не умеет `socks5` с логином и паролем. Для браузерного режима берите HTTP-прокси.
- Для `socks5` в режиме `--source api` нужен дополнительный пакет: `pip install "httpx[socks]"`.
- Прокси меняет только адрес, с которого идут запросы. От капчи и лимитов Яндекса он не спасает:
  капчу по-прежнему решаете вы.

## Официальное API (опционально)

`--source api` использует [«API Поиска по организациям»](https://yandex.ru/maps-api/products/geosearch-api).
Ключ передаётся через `--api-key` или `YANDEX_API_KEY` в `.env` (пример в `.env.example`).

Минусы API:
- оно не отдаёт рейтинг и отзывы, поэтому выводы по SEO и админу будут беднее;
- это платный продукт: тестовый период активирует поддержка Яндекса по запросу, лимиты и цены смотрите на [странице тарифов](https://yandex.com/dev/commercial/doc/ru/concepts/geosearch).

## Важно знать

- **Яндекс не любит автоматический сбор.** Браузерный режим работает как обычный пользователь:
  видимое окно, паузы, капчу решаете вы. Можно задать один прокси, но обходов защиты, ротации прокси, подмены отпечатков и автоматического решения капчи здесь нет.
  Если Яндекс ответил `limited` (ограничение по IP), сделайте перерыв и увеличьте `--delay`.
  Пользовательское соглашение Яндекса ограничивает автоматизированный сбор, так что пользуйтесь
  умеренно и на свой риск.
- **Вёрстка и JSON Яндекс Карт меняются.** Парсер не привязан к конкретному пути в JSON:
  он ищет карточки организаций по всему ответу. Но если после обновления Яндекса данные
  перестанут собираться, нужно будет поправить `yandex_leads/sources/extract.py`.
- **Холодные рассылки.** Звонки, SMS и письма с рекламой без согласия адресата нарушают
  закон «О рекламе» (ст. 18). Телефоны ИП и самозанятых — это персональные данные (152-ФЗ).
  Безопаснее писать от лица живого человека, предлагать бесплатный разбор, а не «купите»,
  и не делать массовых одинаковых рассылок. Черновики в таблице сделаны именно так,
  но перед отправкой их стоит прочитать и поправить.

## Разработка

```bash
pip install -e ".[dev]"
pytest
```

Тесты не ходят в Яндекс. Браузерный сборщик проверяется на подставной странице,
сайты — через mock-транспорт httpx.
